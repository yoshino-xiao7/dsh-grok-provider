## 中文

`0.1.5` 聚焦于已发布 `0.1.4` 之后的维护，不扩展模型协议、认证方式或网络边界。

### 变更

- 发布工作流现在必须从精确稳定 tag ref 启动，并验证该 tag 剥离后的 commit 与工作流 commit 一致。
- 发布前要求 GitHub Release 非草稿、非预发行、tag 精确匹配，且只包含唯一的 `dsh-grok-provider-0.1.5.tgz`；发布 Node.js 固定为 `24.19.0`。
- 账户面板从模型目录的 `inputModalities` 投影能力标签：精确 `grok-4.6` 显示图片输入，text-only 模型不显示。
- Provider Runtime 安装失败时按相反顺序回滚已完成的注册；正常卸载保持幂等，并尽力执行全部清理项。
- 文档同步 `0.1.4` 的最终发布事实，并修正 SSE 只有整体请求期限、没有独立 idle timeout 的表述。

### 兼容性与范围

- DeepSeek Harness：精确 `0.1.1-rc.2`
- Node.js：`>=24.19.0`
- 平台：macOS arm64、Windows x64（Windows 仍为代码与 CI 支持，未声称独立真机验收）
- 图片：沿用 `0.1.4`；只有精确 `grok-4.6` 接收有界 JPEG/PNG attachment，`grok-4.5` 与其他模型保持 text-only
- 不包含 Web/X Search、图片生成、任意 URL 下载、API Key、自定义 endpoint、多账号或新 SSE 事件

发布后安装精确版本：

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.5
dsh web
```

## English

`0.1.5` focuses on maintenance after published `0.1.4`. It does not expand the model protocol, authentication modes, or network boundary.

### Changes

- The publishing workflow must run from the exact stable tag ref and verifies that the peeled tag commit equals the workflow commit.
- Publishing requires a matching, non-draft, non-prerelease GitHub Release with exactly one `dsh-grok-provider-0.1.5.tgz` asset; the publishing runtime is pinned to Node.js `24.19.0`.
- The account dashboard projects capability badges from catalog `inputModalities`: exact `grok-4.6` shows image input while text-only models do not.
- Provider Runtime installation rolls back completed registrations in reverse order after a later failure; normal disposal remains idempotent and attempts every cleanup.
- Documentation records the final `0.1.4` release facts and accurately states that SSE has an overall request deadline, not an independent idle timeout.

### Compatibility and scope

- DeepSeek Harness: exact `0.1.1-rc.2`
- Node.js: `>=24.19.0`
- Platforms: macOS arm64 and Windows x64 (Windows remains code/CI supported without an independent real-device acceptance claim)
- Images: unchanged from `0.1.4`; only exact `grok-4.6` accepts bounded JPEG/PNG attachments, while `grok-4.5` and all other models remain text-only
- Excludes Web/X Search, image generation, arbitrary URL downloads, API-key mode, custom endpoints, multiple accounts, and new SSE events

After publication, install the exact version:

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.5
dsh web
```
