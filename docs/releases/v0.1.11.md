## 中文

`0.1.11` 修复精确 `grok-4.6` 在 **High Effort + Web Search** 续跑时偶发的 `The Grok provider rejected an invalid or unsupported response`。上游会先关闭 reasoning 项，在一次 Search 完成后再把同一个 reasoning ID 使用一次作为空占位项；旧解码器把任何 ID 复用都视为非法响应。

> `0.1.11` 已正式发布。发布提交为 `2e5c6dbc8bb83377a4db4d8e31452b3ce96500c5`；annotated tag object `353bcd3717d4440ab20a2b05a5e9d51eef22fa7f` peel 到该提交。final CI run [`33303080849`](https://github.com/yoshino-xiao7/dsh-grok-provider/actions/runs/33303080849) 的 macOS 14 / Windows 2022 均通过，Trusted Publisher run [`33303631312`](https://github.com/yoshino-xiao7/dsh-grok-provider/actions/runs/33303631312) 已发布仓库所有者明确授权的精确制品。

### 修复内容

- 仅在一次 Search 已完成后允许已经闭合的 reasoning ID 再出现一次，并且第二次必须是严格为空的 reasoning 占位项；无已完成 Search、未闭合复用、跨类型复用、非空复用和第二次重复仍失败关闭。
- 接受完整闭合的空 reasoning 项，同时继续校验事件序号、输出索引、状态和 encrypted replay。
- 支持官方 Responses 的 raw reasoning 标准生命周期：`reasoning_text` content part 以及 `response.reasoning_text.delta` / `done`。
- raw reasoning 与现有 summary reasoning 严格互斥；混用、乱序、重复、缺失完成事件或内容不一致仍返回通用非法响应错误。
- replay 元数据不保存 raw 明文，后续请求只回传 `encrypted_content` 与 `summary: []`，不会回传或把 raw 明文伪装成 summary；当前流中的 raw reasoning delta 仍会作为 Harness 可见 reasoning 输出。

### 验证边界

- 聚焦自动化覆盖空项、一次性 ID 复用、raw reasoning 流式输出与 encrypted replay，以及对应的非法/截断生命周期。
- 脱敏真实探针通过生产解码器完成 1 次 POST：68 个事件、34 个 summary delta、0 个 raw reasoning delta、decoder accepted、1 个 finish。
- 该真实探针证明当前观察到的 **summary + Web Search 续跑路径** 可被接受；因为它没有返回 raw reasoning 事件，所以 **不能**作为 raw reasoning 真机验证。raw reasoning 当前只有协议 fixture 回归证据。

### Fixes

- Permit one reuse of an already closed reasoning ID only after one completed Search and only when the second lifecycle is a strictly empty reasoning placeholder. Reuse without completed Search, open, cross-type, non-empty, or repeated reuse still fails closed.
- Accept fully closed empty reasoning items while preserving sequence, output-index, status, and encrypted-replay validation.
- Support the official Responses raw-reasoning lifecycle: `reasoning_text` content parts and `response.reasoning_text.delta` / `done` events.
- Keep raw reasoning and summary reasoning strictly mutually exclusive. Mixed, out-of-order, duplicate, incomplete, or inconsistent lifecycles still map to the generic invalid-response error.
- Replay metadata does not retain raw plaintext. Later requests carry only `encrypted_content` plus `summary: []` and never replay or relabel raw plaintext as a summary; live raw-reasoning deltas remain visible to Harness.

### Verification boundary

- Focused automation covers empty items, one-time ID reuse, raw-reasoning streaming and encrypted replay, plus the corresponding malformed and truncated lifecycles.
- A redacted real probe passed one POST through the production decoder: 68 events, 34 summary deltas, zero raw-reasoning deltas, decoder accepted, and one finish.
- That probe verifies the currently observed **summary + Web Search continuation path** only. Because it emitted no raw-reasoning events, it is **not** live evidence for raw reasoning; raw reasoning is currently protocol-fixture verified.

### Compatibility and unchanged boundaries

- Search results and citations remain untrusted remote content; the plugin never opens or downloads cited links
