## 中文

`0.1.10` 修复 `0.1.9` 中 Web Search 与 X Search 开关始终不可用的问题。缺陷来自 Host 未注册页面所绑定的 `llm-grok` 设置 namespace；不是登录状态、CLI 版本或用户操作造成的。

### 安装

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.10
dsh web
```

### 修复内容

- 通过 Harness 官方 settings module 注册 `llm-grok`，设置页可读取并写入 Web Search 与 X Search。
- 保留安全默认值：两项均默认关闭，并继续只对精确 `grok-4.6` 开放。
- 设置写入只影响后续调用；每个调用在模型发现前冻结一次策略，已准备和在途请求不会被中途改变。
- 没有 settings provider 时继续使用组合配置；插件卸载或 settings service 重载时由 Harness 生命周期自动清理和回退。
- 新增真实 SettingsProvider + LLM Runtime 集成回归，以及模型目录延迟期间的调用快照回归。

### 不变边界

本版不改变认证、凭据、官方 CLI、固定 endpoint、Search 协议 allowlist、citation 处理、图片输入或平台支持。真实 xAI Search 请求和网络可达的 Windows 真机浏览器弹出仍属于独立验收范围。

<summary>English release notes</summary>

`0.1.10` fixes the Web Search and X Search controls that remained permanently unavailable in `0.1.9`. The Host had not registered the `llm-grok` settings namespace consumed by the page; sign-in state, CLI version, and user actions were not the cause.

### Install

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.10
dsh web
```

### Fixes

- Register `llm-grok` through the canonical Harness settings module so the page can read and persist Web Search and X Search.
- Preserve safe defaults: both settings remain off by default and available only for exact `grok-4.6`.
- Apply committed settings only to later calls. Each call snapshots its policy before model discovery, so prepared and in-flight requests do not change underneath the user.
- Retain composition configuration when no settings provider is mounted, with Harness-owned cleanup and fallback across unload or settings-service reload.
- Add real SettingsProvider + LLM Runtime integration coverage and a deferred-model-discovery call-snapshot regression.

### Unchanged boundaries

Authentication, credentials, the official CLI, fixed endpoints, Search protocol allowlists, citation handling, image input, and platform support are unchanged. Real xAI Search requests and network-reachable browser launch on a physical Windows device remain separate acceptance boundaries.
