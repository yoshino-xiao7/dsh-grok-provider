## 中文

`dsh-grok-provider@0.1.8` 曾短暂发布“仅在当前 Grok 会话显示侧栏额度”的实现，并把侧栏的 Grok 额度查询与展示职责移入 Provider。该变更随后通过回滚合并撤回，本版本不再作为可安装版本提供。

### 撤回状态

- npm Registry 的包名与版本号组合 `dsh-grok-provider@0.1.8` 已被永久占用；即使 unpublish，也不能复用该号码或用它重发不同制品。
- 撤回后 npm Registry 的 `latest` 恢复为 `0.1.7`；后续 Search 已作为独立 `0.1.9` 发布。
- Web/X Search 顺延至 `0.1.9`。

<details>
<summary>English withdrawal record</summary>

`dsh-grok-provider@0.1.8` was briefly published with a Grok-only sidebar quota card, moving sidebar Grok quota querying and rendering into the Provider. The merge was then reverted and the release was withdrawn, so this version is no longer offered for installation.

### Withdrawal status

- The npm Registry package-name/version pair `dsh-grok-provider@0.1.8` is permanently reserved. Unpublishing does not make the number reusable or permit a different artifact to be republished under it.
- After withdrawal, npm Registry `latest` returned to `0.1.7`; the independent Search slice was subsequently published as `0.1.9`.
- Web/X Search moves to `0.1.9`.

</details>
