## 中文

`0.1.8` 为当前 Grok 对话增加紧凑的侧栏额度信息，不改变认证、模型能力或网络端点。

### 变更

- 只有当前会话选择 `grok` Provider 时才显示 Grok 额度卡；DeepSeek、Codex 和其他 Provider 不显示该卡片。
- 卡片展示剩余额度百分比和当前计费周期重置时间，点击可通过既有 loopback dashboard RPC 刷新。
- 浏览器侧仍只接收经过 Host 严格投影的额度与时间，不接收账户身份、预付余额、OAuth 凭据或原始 billing 响应。
- 新增 Harness 模型选择目录和侧栏插槽依赖，不改变官方 CLI 登录、固定 endpoint、模型发现、图片边界或 Responses 传输。

### 兼容性与范围

- DeepSeek Harness：精确 `0.1.1-rc.2`
- Node.js：`>=24.19.0`
- 只显示额度与重置时间，不提供充值或付款入口
- Windows 外部浏览器登录的真实网络环境限制与 `0.1.7` 相同，本版不宣称修复或重新验证

发布后安装精确版本：

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.8
dsh web
```

## English

`0.1.8` adds compact sidebar quota information for the current Grok conversation without changing authentication, model capabilities, or network endpoints.

### Changes

- The Grok quota card renders only while the current conversation selects the `grok` Provider. It stays absent for DeepSeek, Codex, and other Providers.
- The card shows remaining usage and the current billing-period reset time and refreshes through the existing loopback dashboard RPC.
- The browser still receives only strictly projected quota and timing data. Account identity, prepaid balances, OAuth credentials, and raw billing responses remain Host-only.
- Adds the Harness model-directory and sidebar-slot peers without changing official CLI sign-in, fixed endpoints, model discovery, image boundaries, or Responses transport.

### Compatibility and scope

- DeepSeek Harness: exact `0.1.1-rc.2`
- Node.js: `>=24.19.0`
- Displays quota and reset time only; it provides no top-up or payment entry
- Real-network Windows external-browser limitations remain the same as `0.1.7`; this release does not claim a fix or new validation

Install the exact version after publication:

```sh
dsh plugin --profile web add dsh-grok-provider@0.1.8
dsh web
```
